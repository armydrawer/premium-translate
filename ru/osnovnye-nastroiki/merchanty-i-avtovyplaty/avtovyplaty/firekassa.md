## Настройки в личном кабинете мерчанта

Пройдите регистрацию на сайте [Vanilapay](https://web.vanilapay.com/) (при работе с RUB) или на сайте [Gamepay](https://web.gampay.cc/) (при работе с UAH).

Зайдите в личный кабинет, раздел "**Сайты**" -> "**Список сайтов**" и добавьте новый сайт.

<figure><img src="../../../.gitbook/assets/image (749).png" alt=""><figcaption></figcaption></figure>

Заполните указанные поля, кроме "**URL уведомлений**" и "**URL уведомлений для выплат**" и нажмите "**Добавить**".

<figure><img src="../../../.gitbook/assets/image (750).png" alt="" width="563"><figcaption></figcaption></figure>

В открывшемся окне перейдите на вкладку "**API**".

<figure><img src="../../../.gitbook/assets/image (751).png" alt=""><figcaption></figcaption></figure>

Обновите **API Bearer Token** и **API Sign Token**, нажав **"Изменить"** на каждой строке поочередно.

<figure><img src="../../../.gitbook/assets/image (752).png" alt=""><figcaption></figcaption></figure>

Скопируйте ключи и сохраните их в текстовый файл.

## **Настройки модуля**

В панели администратора создайте нового мерчанта в разделе "**Автовыплаты**" -> "**Добавить автовыплату".**

Выберите Firekassa в выпадающем списке в поле "**Модуль**", укажите название для модуля и нажмите "**Сохранить**".

<figure><img src="../../../.gitbook/assets/image (1293).png" alt=""><figcaption></figcaption></figure>

Заполните указанные авторизационные поля.

<figure><img src="../../../.gitbook/assets/image (1309).png" alt=""><figcaption></figcaption></figure>

Домен — оставьте пустым при работе с RUB (используется `https://admin.vanilapay.com`). При работе с UAH укажите `https://admin.gampay.cc`.

API ключ — API Bearer Token из личного кабинета FireKassa.

Секретный ключ — API Sign Token из личного кабинета FireKassa.

## Особые поля

Поля появляются в блоке «Другие настройки» после сохранения ключей.

Способ оплаты — способ выплаты:

* Автоматически — способ определяется по полю «Обозначение для XML» валюты «Получаете»: карта для `CARDRUB`, `SBERRUB` и других карточных обозначений, СБП для `SBPRUB`, ЮMoney для `YAMRUB`. Полный список соответствий приведен в подсказке «Автоматически». Если обозначения нет в списке, автовыплата остановится с ошибкой кода валюты — выберите способ вручную или через доп.поле.
* Доп.поля (Валюты) — использование дополнительного поля валюты.
* Доп.поля (Направление) — использование дополнительного поля направления обмена.
* Способ оплаты — ручной выбор из способов, включенных в вашем личном кабинете.

Кошелек — счет списания в личном кабинете FireKassa:

* Автоматически — первый подключенный счет в валюте заявки, на котором включен выбранный способ выплаты. Если у вас несколько счетов в одной валюте, укажите нужный явно.
* [Доп.поля (Валюты), Доп.поля (Направление)](https://premium.gitbook.io/main/osnovnye-nastroiki/valyuty-i-napravleniya-obmena/dopolnitelnye-polya) — как для способа оплаты.
* Кошелек — ручной выбор счета.

Значения доп.поля должны содержать код из подсказки к настройке, например `SBP (sbp)` или `Рубли (sber)`. Можно указать только код.

Bank code (SBP only) — банк получателя, обязателен для выплаты по СБП. Список банков подгружается из FireKassa. Выберите один банк вручную или доп.поле, в вариантах которого указаны коды банков, например `Сбербанк (100000000111)`.

{% hint style="warning" %}
Выбирайте банк по точному названию: Сбербанк России — 100000000111, а рядом в списке есть Сбербанк Беларусь и Приднестровский Сбербанк.
{% endhint %}

Счет — источник реквизита получателя, по умолчанию «\[Получаете] Счет». Для СБП здесь должен быть телефон получателя: если он запрашивается отдельным доп.полем, выберите это поле.

Account holder и BIC — источники ФИО и БИК получателя для выплаты на банковский счет (способ `Bank account (account)`). Для ФИО можно выбрать «\[Заявка] Фамилия Имя Отчество», для БИК — доп.поле. Для выплаты на счет оба обязательны.

## Статусы выплат

* Выплата проведена — заявка переходит в статус «Выполненная заявка».
* Выплата проведена частично — статус «Частичная выплата».
* Выплата отменена, отклонена или просрочена — статус из настройки «Ошибка статуса API».

{% hint style="warning" %}
Если созданная выплата отменена, отклонена или просрочена, повторная автовыплата по заявке заблокирована. Позднее подтверждение от FireKassa переведет заявку в «Выполненная заявка» или «Частичная выплата». Перед ручной выплатой уточните у FireKassa, не будет ли первая выплата исполнена позже.
{% endhint %}

## Разрешенные IP адреса

Если заполняете поле «Разрешенные IP адреса», укажите все адреса FireKassa, каждый с новой строки:

```
94.250.252.69
178.250.156.196
3.125.233.29
```

## Обновление с версии 2.7.0

* Перенесите адрес из прежнего поля «API url» в поле «Домен», если работаете с UAH.
* Выбранный ранее в поле «Тип» счет не переносится — проверьте поле «Кошелек».
* Раньше все выплаты уходили на карту, теперь способ определяется по обозначению для XML валюты — проверьте «Способ оплаты» для нестандартных обозначений и укажите банк для СБП.
*   Если у рублевой валюты указан код RUR, замените его на RUB.
