## Настройки в личном кабинете мерчанта

Пройдите регистрацию на сайте [Vanilapay](https://web.vanilapay.com/) (при работе с RUB) или на сайте [Gamepay](https://web.gampay.cc/) (при работе с UAH).

Зайдите в личный кабинет, раздел "**Сайты**" -> "**Список сайтов**" и добавьте новый сайт.

<figure><img src="../../../.gitbook/assets/image (749).png" alt=""><figcaption></figcaption></figure>

Заполните указанные поля, кроме "**URL уведомлений**" и "**URL уведомлений для выплат**" и нажмите "**Добавить**".

<figure><img src="../../../.gitbook/assets/image (750).png" alt="" width="563"><figcaption></figcaption></figure>

В открывшемся окне перейдите на вкладку "**API**".

<figure><img src="../../../.gitbook/assets/image (751).png" alt=""><figcaption></figcaption></figure>

Обновите **API Bearer Token** и **API Sign Token**, нажав **"Изменить"** на каждой строке поочередно.

<figure><img src="../../../.gitbook/assets/image (752).png" alt=""><figcaption></figcaption></figure>

Скопируйте ключи и сохраните их в текстовый файл.

## Настройки модуля

В панели администратора создайте нового мерчанта в разделе "**Мерчанты**" -> "**Добавить мерчант".**

Выберите FireKassa в выпадающем списке в поле «Модуль», укажите название для модуля и нажмите «Сохранить».

<figure><img src="../../../.gitbook/assets/image (1286).png" alt=""><figcaption></figcaption></figure>

Заполните указанные авторизационные поля.

<figure><img src="../../../.gitbook/assets/image (1291).png" alt=""><figcaption></figcaption></figure>

Домен — оставьте пустым при работе с RUB (используется `https://admin.vanilapay.com`). При работе с UAH укажите `https://admin.gampay.cc`.

**API ключ** — **API Bearer Token** из личного кабинета Firekassa

**Секретный ключ** — **API Sign Token** из личного кабинета Firekassa

Для обоих типов мерчанта действуют лимиты на стороне FireKassa — уточните их у технической поддержки FireKassa.

{% hint style="warning" %}
Если у рублевой валюты указан код RUR, замените его на RUB.
{% endhint %}

## Тип мерчанта

В настройках модуля доступно два варианта работы:

Payment link — в заявке выводится кнопка перехода на платежную форму FireKassa. Форма показывает все способы оплаты, подключенные в вашем личном кабинете для валюты заявки.

Requisites — реквизиты на оплату (номер карты или номер телефона для СБП) и получатель выдаются прямо в заявке.

Тип мерчанта можно изменить, пока по этой копии модуля нет заявок. После первой заявки он фиксируется — для другого типа создайте отдельную копию модуля.

## Особые поля

Поля появляются в блоке «Другие настройки» после сохранения ключей.

Способ оплаты:

* Автоматически — способ определяется по полю «Обозначение для XML» валюты «Отдаете»: карта для `CARDRUB`, `SBERRUB` и других карточных обозначений, СБП для `SBPRUB`. Полный список соответствий приведен в подсказке «Автоматически». Если обозначения нет в списке, выберите способ вручную или через доп.поле.
* [Доп.поля (Валюты)](https://premium.gitbook.io/main/osnovnye-nastroiki/valyuty-i-napravleniya-obmena/dopolnitelnye-polya?utm_source=chatgpt.com#dopolnitelnye-polya-dlya-valyuty) — использование дополнительного поля валюты.
* [Доп.поля (Направление)](https://premium.gitbook.io/main/osnovnye-nastroiki/valyuty-i-napravleniya-obmena/dopolnitelnye-polya?utm_source=chatgpt.com#dopolnitelnye-polya-dlya-napravleniya-obmena) — использование дополнительного поля направления обмена.
* Способ оплаты — ручной выбор из способов, включенных в вашем личном кабинете.

Кошелек — счет зачисления в личном кабинете FireKassa:

* Автоматически — первый подключенный счет в валюте заявки, на котором включен выбранный способ оплаты.
* Доп.поля (Валюты), Доп.поля (Направление) — как для способа оплаты.
* Кошелек — ручной выбор счета.

Значения доп.поля должны содержать код из подсказки к настройке, например `Card (card)`, `SBP (sbp-a)` или `Рубли (sber)`. Можно указать только код.

#### Кнопка оплаты и QR-код

Если FireKassa возвращает ссылку на оплату вместе с реквизитами, ее можно показать в заявке в виде кнопки или QR-кода.

В поле «Инструкция по оплате для пользователя» нажмите тег «Ссылка на оплату» — в текст вставится готовый блок:

```html

[if_pay_firekassa]<a href="{pay_url}" target="_blank" rel="noopener">{pay_url}</a><br>{pay_qr}[else][/if_pay_firekassa]

```

* `{pay_url}` — ссылка на оплату.
* `{pay_qr}` — QR-код ссылки; для его отображения включите модуль «QR код генератор».
* Текст между `[else]` и `[/if_pay_firekassa]` выводится, если ссылки нет.

Разметку внутри блока можно менять, например оформить ссылку кнопкой

### Недоплата и переплата

* **Недоплата** — заявка переходит в статус «Ожидание подтверждения от мерчанта» с фактически полученной суммой. Доплаты обновляют сумму, полная оплата зачисляет заявку.
* **Переплата** — обработка зависит от настройки «Сумма платежа больше чем требуется»: оставить прежний статус, отправить заявку на проверку или отметить оплаченной.
* **Ошибка платежа** — если FireKassa возвращает статус `ERROR`, заявка переводится в статус ошибки мерчанта.

{% hint style="warning" %}
Если в направлении включен пересчет суммы обмена для статуса «Ожидание подтверждения от мерчанта», включите его и для статуса «Оплаченная заявка» — иначе после доплаты выдача останется уменьшенной.
{% endhint %}

### Разрешенные IP адреса

Если заполняете поле «Разрешенные IP адреса», укажите все адреса FireKassa, каждый с новой строки:

```
94.250.252.69
178.250.156.196
3.125.233.29
```

### **Выполнение требований Firekassa**

Требование мерчанта — передача номера телефона клиента, который он должен вводить в форме обмена. Для этого в настройках направления (вкладка "**Доп. поля**") установите галочку напротив поля "**Телефон**" (убедитесь, что поле обязательно для заполнения — в форме обмена должна отображаться <mark style="color:red;">красная звездочка</mark> для этого поля)
