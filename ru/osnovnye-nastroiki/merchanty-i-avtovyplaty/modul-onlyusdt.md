<figure><img src="../../.gitbook/assets/image (1160).png" alt=""><figcaption></figcaption></figure>

Для настройки модуля перейдите в раздел "**Заявки - TRON enegry**".

**API ключ —** укажите API ключ сформированный ранее в боте OnlyUSDT.&#x20;

<figure><img src="../../.gitbook/assets/image (1168).png" alt=""><figcaption></figcaption></figure>

## Покупка энергии

{% hint style="warning" %}
Арендованная энергия доступна временно, 30 минут с покупки по кнопке "Применить".\
Арендуйте энергию прямо перед проведением фактической выплаты с кошелька.
{% endhint %}

<figure><img src="../../.gitbook/assets/image (1177).png" alt=""><figcaption></figcaption></figure>

Для аренды энергии нужно выбрать кошелек и тариф, затем нажать "Применить".

В поле выше будет отображена количество арендованной энергии или ошибка и ее причина.

{% hint style="info" %}
Для аренды доступно два тарифа:\
1 - 66 000 энергии, стоимость одного перевода USDT TRC20, примерно 2.3 TRX.\
2 - 135 000 энергии, два перевода или один перевод на новый кошелек, где USDT еще не использовалось. Такой перевод требует в два раза больше энергии.
{% endhint %}

<details>

<summary>Ошибка "Адрес не активирован".</summary>

Если для выплат вы указываете кошелек, который еще не был использован - можете получить ошибку "address is not activated".

<figure><img src="../../.gitbook/assets/image (1179).png" alt=""><figcaption></figcaption></figure>

Активировать такой адрес можно отправив на него средства для будущиъ выплат или по специальной кнопке в боте OnlyUSDT в разделе "Энергия".

</details>

Аренда энергии выполняется за TRX на балансе вашего кошелька в боте OnlyUSDT.

Пополнить такое кошелек можно прямо в боте через TRX или USDT.&#x20;

## Партнёрская программа OnlyUSDT

Сервис OnlyUSDT предлагает партнерскую программу для получения дохода с операций ваших рефералов. Ознакомиться с условиями и сформировать свою реферальную ссылку можно в боте, раздел "Личный кабинет - Реферальная программа".

<details>

<summary>Описание партнерской программы.</summary>

👥 Реферальная программа\
\
Получайте пассивный доход с операций ваших рефералов и их приглашённых пользователей.

💰 Доход:\
\
Частное использование:\
• L1: 7.00%\
• L2: 1.50%\
• L3: 0.50%\
\
Через API:\
• L1: 5.00%\
• L2: 1.50%\
• L3: 0.50%\
\
📊 Статистика:\
Рефералов:\
• L1: 1\
• L2: 0\
• L3: 0\
\
Баланс: 0.000000 TRX\
\
Заработано всего: 0 TRX\
За месяц: 0 TRX\
\
По уровням:\
• L1: 0 TRX\
• L2: 0 TRX\
• L3: 0 TRX

🚀 Приглашайте пользователей, обменники, сервисы и API-проекты — получайте доход с каждого уровня вашей команды.
